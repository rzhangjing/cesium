- 构建脚本统一通过 `defaultESBuildOptions()` 返回共享配置对象（bundle/color/legalComments/logLimit/target），再按需覆盖 format/outfile/plugins，避免重复声明 esbuild 选项。
- 源码聚合采用“globby 扫描 + 动态生成导出文件”模式：`createIndexJs`/`createCesiumJs`/`createCombinedSpecList` 都遍历 `workspaceSourceFiles` 映射，把路径转为模块 ID 后拼接成 `export { ... } from '@cesium/...'` 语句写入目标文件。
- 调试开关通过 `//>>includeStart(pragma)/includeEnd(pragma)` 注释块包裹，由 `stripPragmaPlugin` 在加载阶段用正则匹配并删除，pragmas 集合集中在 `const pragmas = { debug: false }` 中集中管理。
- 所有生成的 JS 文件头部固定插入 `//This file is automatically rebuilt by the Cesium build process.` 注释，并通过 `getCopyrightHeader()` 注入 `${version}` 占位符。
- 增量构建统一采用 `const build = options.incremental ? esbuild.context : esbuild.build` 分支，并在非写盘模式下对 `BuildResult.warnings` 调用 `handleBuildWarning` 过滤第三方库告警。
