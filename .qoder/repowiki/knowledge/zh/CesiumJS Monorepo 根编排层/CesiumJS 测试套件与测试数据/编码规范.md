- 浏览器 spec 通过 URL query 参数（`category`/`not`/`webglValidation`/`webglStub`/`debugCanvasWidth`/`debugCanvasHeight`）控制运行行为，而非环境变量或配置文件。
- 测试套件使用带 category 参数的 `describe(name, suite, category)` 形式对用例分组，由 `customizeJasmine.js` 统一拦截并按 `includedCategory`/`excludedCategory` 过滤。
- 每个 3D Tiles / glTF / CZML 等数据用例以独立子目录存放，包含 `tileset.json` 或 `.gltf` 等资源文件，命名采用 PascalCase 描述特性组合（如 `BatchedWithBatchTableBinary`、`PointCloudDracoInvalid`）。
- E2E 测试通过 `CesiumPage.goto()` 动态注入 `CESIUM_BASE_URL`，根据 `process.env.release` 切换 `Build/Cesium` 与 `Build/CesiumUnminified` 两套构建产物。
- 共享测试工具（`createScene.js`、`createCamera.js`、`MockImageryProvider.js`、`pollWhilePromise.js` 等）以 ES module 形式从 `Specs/` 根目录被各 spec 按需 import，避免重复构造场景。
