本模块为纯资源型叶子，不含可执行代码，由两个 HTML 入口和大量静态数据组成：
- `HelloWorld.html`：最简单页，通过 `<script src="../Build/CesiumUnminified/Cesium.js">` 引用构建产物中的全局 `Cesium` 命名空间，仅创建 `new Cesium.Viewer`。
- `CesiumViewer/`：功能更完整的独立 viewer 应用，`index.html` 引入本地 `CesiumViewer.css` 与 ES module 形式的 `CesiumViewer.js`；`CesiumViewer.js` 通过 `window.CESIUM_BASE_URL` 定位 `../../Build/CesiumUnminified/index.js`，使用 ESM import 按需加载 `Viewer`、各类 `DataSource`、`Terrain`、`ImageryLayer` 等 API，并解析 URL query string（`source`、`sourceType`、`flyTo`、`tmsImageryUrl`、`inspector`、`debug`、`theme`、`scene3DOnly`、`view`、`saveCamera`、`lookAt`、`stats`）动态装配 Viewer、地形、影像层、拖拽与 Inspector mixin。
- `SampleData/`：按格式分目录组织的只读测试数据，包括 `Cesium3DTiles/`（b3dm/i3dm/pnts/cmpt/vtile 瓦片集）、`models/`（glb/gltf/dae）、`gpx/kml/vector/`、`.czml/.geojson/topojson` 等，被上述两个页面及文档站点直接以相对路径引用，不参与构建流程。
