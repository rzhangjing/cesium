本模块是 cesiumrust 工作区中的独立 crate `cesium-provider`，位于 domain 层，声明为纯 Rust、f64 精度，不依赖任何网络 I/O 或渲染后端。

- 包边界：`Cargo.toml` 仅引入 `glam` 和同仓库的 `cesium-geospatial`，无外部运行时依赖，保证领域模型可被 Bevy 应用层自由组合。
- 子模块划分：`lib.rs` 通过 `pub mod` + `pub use` 重导出两个子模块——`imagery_provider`（影像瓦片 URL 生成）与 `terrain_provider`（地形高程数据），对外只暴露构造器与 `get_tile_url`/`is_available` 等纯函数式 API。
- 领域实体：每个具体提供者（如 `UrlTemplateImageryProvider`、`WmtsImageryProvider`、`CesiumTerrainProvider`）都是不可变配置结构体，配合 builder 风格的 `with_*` 方法链式装配；URL 构建逻辑封装在各自的 `get_tile_url` 中，不包含请求发送。
- 策略枚举：`SubdomainStrategy`（RoundRobin/None）与 `AvailabilityStrategy`（All/TilingScheme/LayerJson）以枚举形式注入行为，避免多态继承，保持结构体简单可 Clone。
- 坐标与投影：共享 `TileCoord { x, y, level }` 作为瓦片坐标抽象；WMS 使用 EPSG:4326 地理分块计算 bbox，TMS 通过 `reverseY = tiles_y - 1 - y` 处理左下角原点差异，Bing 提供 `tile_to_quadkey` 四叉键转换。
- 测试内聚：每个提供者文件末尾附带 `#[cfg(test)] mod tests`，用断言覆盖 URL 拼接、quadkey、availability 等关键路径，确保领域逻辑回归稳定。
