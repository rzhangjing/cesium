本 crate `cesium-styling` 是 DDD 中的纯领域层，仅依赖 `glam`，不耦合渲染或 Bevy。
- `lib.rs` 作为门面，通过 `pub use` 将两个子模块的公共类型提升到 crate 根：`classification::{Classification, ClassificationCollection, ClassificationType, FeatureMetadata, MetadataValue}` 与 `tile_style::{ArithmeticOp, CompareOp, PropertyValue, StyleExpression, TileStyle}`。
- `tile_style.rs` 定义样式语言 AST：`StyleExpression` 枚举覆盖常量、属性引用、三元条件、比较/算术/逻辑运算与函数调用；`PropertyValue` 为运行时值域；`TileStyle` 暴露 `evaluate_show / evaluate_color / evaluate_point_size` 三个面向瓦片管线的评价入口，内部通过递归 `evaluate` + `is_truthy` + `compare` + `arithmetic` + `evaluate_function` 完成求值，内置 `color/rgb/rgba/abs/sqrt/min/max/clamp` 等函数及 CSS/hex 颜色解析。
- `classification.rs` 定义 `ClassificationType`（Both/Terrain/Cesium3DTile）、`Classification`（按 feature_id/batch_id 过滤）与 `ClassificationCollection`（集合级 alpha 混合），以及 `FeatureMetadata` 与 `MetadataValue` 用于属性表索引与自定义属性。
- 依赖方向单向：上层渲染/调度模块通过 crate 公开 API 消费样式求值与分类结果，本模块不反向依赖任何子系统。
