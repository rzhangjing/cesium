- Domain crate 保持无框架依赖，仅通过 workspace path 引用其他 domain crate（如 `cesium-scene` → `cesium-geospatial`、`cesium-camera`），禁止跨层反向依赖。
- 所有浮点断言统一使用 `specs` crate 提供的 `assert_approx!` / `assert_vec*_epsilon!` / `assert_mat*_epsilon!` 宏配合 `epsilon::EPSILONn` 常量，而非裸 `assert!((a-b).abs() < eps)`。
- glam 向量类型统一使用 `DVec2/DVec3/DVec4`（f64 精度），并在 epsilon 比较时先转为 f64 再计算差值，保证与 CesiumJS 的 double 语义一致。
- 每个 domain crate 的 `Cargo.toml` 通过 `version.workspace = true` 和 `publish.workspace = true` 继承工作区级版本与发布策略，避免重复声明。
- 测试文件按 CesiumJS 原始目录镜像组织在 `specs/tests/<module>/` 下（如 `core/`、`datasources/`），便于逐条对照原 Specs 进行审计与补全。
- 数值相关 crate 在注释中显式记录与 CesiumJS 模块的映射关系（如 `domain/geospatial/src/lib.rs` 头部注释标注对应 `packages/engine/Source/Core/`），作为架构追溯依据。
