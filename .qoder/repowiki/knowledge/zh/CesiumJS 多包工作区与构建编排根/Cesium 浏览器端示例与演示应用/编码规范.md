- HTML 模板统一包含 charset、IE=edge、viewport 三组 meta 标签，并将容器 div 设为全屏样式。
- 通过 URL query string（如 `source=`、`sourceType=`、`flyTo=`、`inspector=`、`theme=`、`view=`）驱动 Viewer 行为，而非配置文件或命令行参数。
- 数据源类型优先基于文件扩展名自动推断（.czml/.geojson/.kml/.gpx），仅在显式指定 `sourceType` 时覆盖。
- 所有异步加载（DataSource.load、ImageryLayer.fromProviderAsync）均包裹 try/catch，并通过 `viewer.cesiumWidget.showErrorPanel` 或 `formatError` 向用户反馈错误。
