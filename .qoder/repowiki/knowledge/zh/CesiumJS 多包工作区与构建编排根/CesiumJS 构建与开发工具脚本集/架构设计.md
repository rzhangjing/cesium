本模块是纯 Node.js ESM 脚本集合，按职责拆分为独立文件，无运行时依赖关系（除 build.js 被 buildSandcastle.js 复用外），由根 package.json 的 npm scripts 或 CI 直接调用。

- 核心构建器 `build.js`：通过 esbuild 同时产出 ESM/IIFE/CJS 三种格式，支持增量构建（esbuild.context）、自定义插件 strip-pragmas 与 external-cesium、glsl-strip-comments 预处理 GLSL；负责为 engine/widgets 两个 workspace 生成 index.js 入口、SpecList.js 测试清单、Workers 打包以及 CSS/Assets 拷贝。
- Sandcastle 构建器 `buildSandcastle.js`：作为沙箱应用构建门面，读取 `packages/sandcastle/sandcastle.config.js`，根据 outputToBuildDir 选择输出到 Build/Sandcastle2 或 Apps/Sandcastle2，并调用 sandcastle 包的 buildStatic/buildGallery 完成静态站点与画廊索引。
- 开发服务器路由 `createRoute.js` + `ContextCache.js`：封装 Express 中间件，基于 ContextCache 缓存 esbuild BuildResult，在首次请求时触发 rebuild 并返回内存中的 outputFiles，避免磁盘 I/O。
- 辅助脚本：`diff-types.sh` 切换分支对比 Cesium.d.ts；`isCI.js` 仅检查 CI 环境变量后以退出码表达结果；`lebab-batch.js` 对首字母大写的 JS 文件批量执行 class 语法转换。

依赖方向：buildSandcastle.js → build.js（getVersion）；createRoute.js → ContextCache.js；其余脚本相互独立。
