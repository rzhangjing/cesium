仓库采用 JS/TS 与 Rust 双栈并列布局：
- JavaScript 侧（根目录）以 npm workspaces 组织 `packages/engine`、`packages/widgets`、`packages/sandcastle` 三个包，通过 Gulp + esbuild 管线（`gulpfile.js`、`scripts/build.js`）将 `Source/**/*.js` 编译为 ESM/CJS/IIFE 产物并输出到 `Build/`；`index.cjs` / `index.html` 作为运行时入口。
- 测试体系分层：Jasmine + Karma 跑 Specs 单元测试，Playwright 在 `Specs/e2e/` 下做端到端场景验证，`Specs/TestWorkers/` 提供 Web Worker 桩。
- 文档由 JSDoc + 自定义模板（`Tools/jsdoc/`）生成，Sandcastle 示例位于 `Apps/Sandcastle`。
- Rust 侧（`cesiumrust/`）是独立 Cargo workspace，按 DDD + 六边形架构分层：`domain/*` 纯 Rust 限界上下文（geospatial/time/camera/scene/tileset/gltf/imagery/terrain/…），`ports/driven` 与 `ports/driving` 定义端口契约，`adapters/bevy-render`、`adapters/decoders`、`adapters/network` 实现具体适配层，`application/cesium-app` 组装 Bevy App 作为默认成员。依赖方向严格单向：adapter → port → domain，domain 不依赖任何框架。
