- Rust 子项目每个限界上下文独立为一个 crate（如 `domain/geospatial`、`domain/tileset`），并通过 `Cargo.toml` 的 `[workspace.dependencies]` 集中声明版本，避免重复锁定。
- 领域层 crate 仅依赖基础库（glam、serde、thiserror），禁止引入 Bevy 等框架依赖，确保 domain 与渲染解耦。
- 适配器层 crate 名称遵循 `cesium-<role>` 前缀（bevy-render、decoders、network），并通过 `path = "..."` 指向内部模块，统一由顶层 workspace 聚合。
- JavaScript 源文件通过 Gulp 任务按 `sourceFiles` glob 模式收集，排除 `ThirdParty`、`Shaders`、`_` 前缀等特定路径，保持构建清单单一来源。
- 测试用例命名以 `*Spec.js` 结尾，并由 `createCombinedSpecList()` 动态汇总，避免手动维护 Spec 列表。
