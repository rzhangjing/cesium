本仓库包含两套并行的测试体系：
- JavaScript Specs（根目录 `Specs/`）：基于 Jasmine + Karma 的浏览器端测试，通过 `SpecRunner.html` 加载 Cesium 构建产物，使用 `spec-main.js` 初始化环境并按 category/spec 过滤执行，配套大量测试数据位于 `Specs/Data/`。
- Rust 集成测试（`cesiumrust/specs/`）：独立的 Cargo crate `cesium-specs`，依赖 workspace 下全部 domain crate（geospatial、time、camera、scene、datasource 等），按 `tests/core/`、`tests/datasources/`、`tests/renderer/`、`tests/scene/`、`tests/widgets/` 等子目录对应 CesiumJS 的模块划分，每个 `.rs` 文件对应一个 JS Spec 文件。
- 构建与运行由根 `gulpfile.js` 驱动，通过 `gulp test` / `npm test` 启动 Karma，Rust 侧通过 `cargo test -p cesium-specs` 运行。
- 依赖方向单向：Rust specs → domain crates，不反向依赖；JS specs → Build/CesiumUnminified 产物，两者互不耦合。
