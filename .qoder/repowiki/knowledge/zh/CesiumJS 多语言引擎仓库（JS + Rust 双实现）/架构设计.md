仓库采用「单一 JS 发布包 + 多语言移植」的聚合结构：根目录通过 package.json 的 workspaces 管理 packages/engine、packages/widgets、packages/sandcastle 三个子包，由 gulpfile.js 串联 build/test/release/coverage/doc 等跨子模块任务；Source/ 提供 CesiumJS 源码，Specs/ 用 Jasmine+Karma+Playwright 对 JS 引擎进行单元与 e2e 测试，Apps/ 与 Documentation/ 作为示例与文档资源。cesium-rs 与 cesiumrust 是独立 Cargo workspace，分别按一比一镜像和领域驱动方式移植 CesiumJS 核心能力，二者共享仓库根提供的测试数据（Specs/Data）、GLSL shader 参考（Documentation/Fabric 与 cesium-rs/shaders）以及 Cesium3DTiles/CZML/KML 等格式规范，从而在 JS 与 Rust 之间形成「同一份数据/规范 → 两套实现」的对齐关系。根层不直接耦合两个 Rust 工程，仅通过 .github/workflows、launches/*.launch 与 Scripts 中的脚本触发各自构建流程。
