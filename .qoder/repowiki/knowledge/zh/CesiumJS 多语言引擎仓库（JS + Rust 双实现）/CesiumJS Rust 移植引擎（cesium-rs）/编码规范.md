- 每个移植后的 `.rs` 文件以 `//! Ported from packages/engine/Source/<模块>/<文件>.js` 注释锚定原始 JS 来源，便于 diff 追踪。
- 领域计算一律使用 `f64`，仅在 `cesium-renderer` 写入 GPU 缓冲或 uniform 时转换为 `f32`，不引入 glam 等第三方数学库。
- CesiumJS 的 `result` 出参模式映射为 `&mut Self` 返回 `()` 的方法，并配套 `_new` 后缀的分配变体（如 `add` / `add_new`）。
- CesiumJS 的 `includeStart('debug', ...)` 区块在 Rust 中用 `#[cfg(debug_assertions)]` 包裹，release 构建自动裁剪调试检查。
- 任何与 CesiumJS 行为不一致的实现必须在代码处标注 `// DEVIATION:` 并在 `docs/deviations.md` 登记，否则视为移植缺陷。
- 超大源文件（≥100KB）允许拆分为同名目录子模块（含 `mod.rs` 聚合导出），但不得跨文件合并或重命名语义单元。
