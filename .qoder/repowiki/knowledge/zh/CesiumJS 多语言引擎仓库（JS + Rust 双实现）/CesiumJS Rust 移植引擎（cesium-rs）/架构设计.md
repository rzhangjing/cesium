采用 Cargo workspace 多 crate 分层组织，严格镜像 `packages/engine/Source/*` 目录结构：
- `crates/cesium-core`：领域层，包含数学类型（Cartesian3/Matrix4/Ellipsoid）、几何体、地形提供者（Cesium3DTiles/Heightmap/QuantizedMesh）、地理投影、时间/事件/请求调度等，所有领域计算使用 `f64`。
- `crates/cesium-renderer`：GPU 抽象层，基于 wgpu（启用 webgl 特性以支持 WebGL2 回退），封装 Context/Buffer/Texture/ShaderProgram/DrawCommand/Pass 等，是 `f64` → `f32` 降维的唯一边界。
- `crates/cesium-shaders`：将 CesiumJS GLSL shader 源文件作为内嵌资源编译进二进制，并通过 `gen_all.ps1` / `gen_shader_modules.ps1` / `gen_structs.ps1` 生成对应的 Rust 模块（Appearances/Materials/Model/PostProcessStages/Voxels/Builtin）。
- `crates/cesium-scene`、`cesium-data-sources`、`cesium-workers`、`cesium-widgets`：上层场景/数据源/Worker/Widget 适配层，依赖 cesium-core。
- `specs/`：Jasmine spec 的一比一 Rust 移植，每个 `it(...)` 对应一个 `#[test] fn`，通过 `cesium-test-utils` 提供断言宏。
- `examples/viewer-demo`：基于 wgpu 的最小可运行示例。
依赖方向单向：scene/widgets/data-sources/workers → renderer/core；shaders 仅依赖 core；specs 为独立测试 crate。
