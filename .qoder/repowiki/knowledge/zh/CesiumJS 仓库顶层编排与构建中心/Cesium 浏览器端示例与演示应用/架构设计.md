本模块为纯前端静态资源集合，无构建产物或运行时依赖，由根目录 `Build/CesiumUnminified/` 下的 Cesium 发行包按需引入。

- `HelloWorld.html`：单文件最小示例，通过 `<script src="../Build/CesiumUnminified/Cesium.js">` 加载全局命名空间 `Cesium`，仅创建 `new Cesium.Viewer` 展示空白地球。
- `CesiumViewer/`：完整交互式 viewer 应用，入口 `index.html` 以 ES module 方式加载 `CesiumViewer.js`，后者从 `../../Build/CesiumUnminified/index.js` 使用具名导入（`Cartesian3`、`Viewer`、`viewerDragDropMixin`、`viewerCesiumInspectorMixin` 等），并通过 `window.CESIUM_BASE_URL` 控制 Cesium 内部资源路径。
- `SampleData/`：按格式分目录组织的静态测试数据集，包括 `Cesium3DTiles/*`（b3dm/i3dm/pnts/cmpt/gltf 瓦片集）、`models/*`（glTF/GLB 模型）、`gpx/kml/czml/vector` 等地理数据，供 CesiumViewer 通过 URL 参数 `source=` 动态加载。
- 依赖方向单向：两个 HTML 页面 → Build 产出的 Cesium JS → SampleData 中的静态资源；模块之间不存在相互引用。
