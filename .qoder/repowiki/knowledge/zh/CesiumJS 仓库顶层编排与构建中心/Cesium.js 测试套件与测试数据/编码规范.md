- 测试辅助工厂统一以 `createXxx(options)` 形式暴露，默认值通过 `options = options ?? {}` 合并，避免在 spec 中重复配置。
- 通过 URL query 参数（`category`/`not`/`spec`/`webglValidation`/`webglStub`/`debugCanvasWidth`/`debugCanvasHeight`）驱动测试行为，而非环境变量或配置文件。
- Jasmine 的 `describe(name, suite, category)` 第三个参数用于分类过滤，配合 `customizeJasmine.js` 中的重写逻辑实现按类别选择/排除。
- 需要销毁的 Scene/Canvas 对象统一挂载 `destroyForSpecs`、`renderForSpecs`、`pickForSpecs` 方法，便于 spec 生命周期管理。
- 测试数据按协议/格式在 `Data/` 下建立同名子目录，每个用例一个文件夹，包含最小化的 tileset.json/gltf/terrain 等文件，命名体现变体（如 `BatchedWith*`、`PointCloudQuantizedOctEncoded`）。
