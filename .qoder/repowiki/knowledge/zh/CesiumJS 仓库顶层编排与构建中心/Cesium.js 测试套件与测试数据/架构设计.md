本模块是纯测试资源与运行期辅助代码，不包含业务逻辑，按职责分为四层：
- 入口与运行时：`SpecRunner.html` + `spec-main.js` + `customizeJasmine.js` 构成浏览器端 Jasmine 启动链，通过 URL query（`category`/`not`/`spec`/`webglValidation`/`webglStub`/`debugCanvasWidth`）动态过滤 spec 并注入全局标志；`karma.conf.cjs` 将同一套源码交给 Karma 在 Chrome 中无头执行。
- 测试辅助工具：以 `create*.js` 命名的工厂函数（`createScene`、`createGlobe`、`createFrameState`、`createCamera`、`createContext`、`createCanvas`、`getWebGLStub` 等）封装 WebGL/Scene 初始化，供各 spec 复用；`pollToPromise`、`runLater`、`waitForLoaderProcess`、`loaderProcess.js` 处理异步渲染与 Worker 通信；`MockImageryProvider`、`MockTerrainProvider`、`MockDataSource` 提供轻量模拟实现。
- 领域专用测试器：`Cesium3DTilesTester.js`、`ImplicitTilingTester.js`、`MetadataTester.js`、`TerrainTileProcessor.js`、`ViewportPrimitive.js` 等针对 3D Tiles / 隐式瓦片 / 元数据 / 地形等子系统编写的高阶断言与可视化辅助。
- 测试数据仓库 `Data/`：按协议/格式分目录（`Cesium3DTiles`、`CZML`、`KML`、`Models/glTF-2.0`、`CesiumTerrainTileJson`、`ArcGIS`、`WMS`、`Images`、`Videos`、`EarthOrientationParameters`、`EnvironmentMap`、`Fonts`），每个子集包含真实或最小化样例文件，由 `karma.conf.cjs` 中的 `proxies` 映射到 `/base/Specs/Data` 供测试加载。
- E2E 层 `e2e/`：独立于 Jasmine，使用 Playwright 对已构建产物进行跨浏览器截图回归，`playwright.config.js` 通过 `npm run start -- --production` 拉起 dev/sandcastle 服务器，输出 HTML 报告至 `Build/Specs/e2e/report`。
依赖方向单向：所有 spec 与 helper 仅依赖 `../packages/engine/index.js`（即已构建的 Cesium 库），不反向引用被测源码。
