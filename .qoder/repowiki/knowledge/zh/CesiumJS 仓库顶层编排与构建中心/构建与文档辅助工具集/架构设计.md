本模块是纯工具集合，按功能拆分为三个独立子目录，彼此无依赖：
- jsdoc/：JSDoc 3 的自定义插件与主题。cesiumTags.js 通过 exports.defineTags 向 JSDoc 注册 @internalConstructor、@glsl*、@performance、@demo、@experimental、@privateParam、@import 等标签；conf.json 指定扫描 packages/engine/Source 与 packages/widgets/Source，并加载该插件；ts-conf.json/tsconfig.json 用于 TypeScript 源码文档生成；cesium_template/ 包含完整的 JSDoc 主题（publish.js + tmpl/*.tmpl + static/*），输出到 Build/Documentation。
- ast-grep/rules/ 与 tests/：成对存放 ast-grep YAML 规则与对应测试用例，每条规则一个 .yml 文件，测试使用 valid/invalid 样例配合 __snapshots__/ 快照断言，覆盖 packages/engine/Source/**/*.js 中的导出冻结、JSDoc 约束、静态字段等规范。
- rollup-plugin-strip-pragma/：基于 magic-string 与 rollup-pluginutils 的 Rollup 插件，匹配 //>>includeStart(...)/ //>>includeEnd(...) 注释块，在打包阶段将其内容替换为空字符串，实现条件编译。顶层 Tools/package.json 仅声明 type: commonjs，使各子工具以 CommonJS 形式被主工程 require。
