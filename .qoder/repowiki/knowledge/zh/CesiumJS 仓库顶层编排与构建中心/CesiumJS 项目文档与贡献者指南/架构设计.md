本模块为纯静态文档集合，按主题划分为若干并列子目录：
- `Contributors/`：面向贡献者的流程文档（构建、CI、编码规范、测试、性能测试、代码审查、发布、CLA 等），每个子目录以 `README.md` 作为入口，并附带截图或 PDF 附件。
- `CustomShaderGuide/`、`OfflineGuide/`：面向最终用户的专题指南。
- `FabricGuide/`：Fabric 材质系统的图文说明，配套大量 PNG 渲染结果图。
- `Images/`：通用 API 截图资源库，命名遵循 `<API>.<方法>.<变体>.png` 的约定，被各指南引用。
- `Schemas/Fabric/Material.schema.json`：Fabric Material JSON 的 JSON Schema 定义，配合 `Examples/*.json` 示例文件，用于校验材质描述文件的合法性。
依赖方向单向：所有子目录仅通过相对路径互相引用 Markdown 中的图片与链接，无脚本或构建产物，属于只读型仓库内容。
