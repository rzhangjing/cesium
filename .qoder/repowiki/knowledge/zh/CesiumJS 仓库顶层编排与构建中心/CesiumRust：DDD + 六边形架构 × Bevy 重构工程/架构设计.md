工作区根 `Cargo.toml` 以三层划分成员：
- `domain/`（cesium-geospatial、time、camera、event、resource）为纯 Rust 领域层，零框架依赖，按地理空间数学、时间、相机等限界上下文拆分；其中 geospatial 子模块直接映射 CesiumJS `packages/engine/Source/Core/` 的椭球、坐标、投影、瓦片方案、包围体、射线/视锥裁剪等。
- `ports/` 定义双向端口契约：`driven/` 暴露 TileFetcher/GpuSink/Decoder/Cache/Clock 等被驱动接口供领域调用，`driving/` 暴露 SceneUseCase/CameraControl/TimeControl/DataCmd 等驱动接口供外部实现。
- `application/cesium-app` 为 Bevy App 装配层，负责系统编排与插件注册，仅依赖 domain + ports，不反向依赖具体基础设施。
- `crates/` 下同时保留 GPUI/Zed 风格 UI 骨架（app/workspace/ui/actions/theme/util/bevy_demo），作为未来 Bevy ECS 渲染管线与 UI 面板的承载容器。
依赖方向严格单向：application → ports → domain，domain 内部各 crate 相互独立，通过 workspace.dependencies 统一版本管理。
