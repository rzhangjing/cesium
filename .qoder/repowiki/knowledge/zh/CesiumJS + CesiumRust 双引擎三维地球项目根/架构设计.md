根目录作为多语言多 crate 的聚合层，将三个子系统通过脚本与配置文件串联：
- JavaScript 侧：Source/ 为 CesiumJS 源码，packages/{engine,widgets,sandcastle} 为 npm workspace 子包，Apps/ 提供示例应用，Specs/ 存放 Jasmine/Karma 单元测试与 Playwright E2E。
- Rust 侧：cesiumrust/ 为独立 Cargo workspace，按 domain/adapters/application/ports 分层实现与 Bevy 渲染集成。
- 构建与质量：gulpfile.js/gulpfile.apps.js/gulpfile.makezip.js 统一 JS 构建；scripts/ 提供 build.js、buildSandcastle.js 等脚手架；.github/workflows/ 与 .husky/pre-commit 驱动 CI/CD；Tools/ 包含 ast-grep 规则、JSDoc 模板与 rollup-plugin-strip-pragma。
- 数据与验证：Specs/Data/ 与 Apps/SampleData/ 共享同一份测试数据集（glTF、3DTiles、KML、GPX、CZML 等），确保 JS 与 Rust 两端使用相同基准数据。
- 入口与发布：index.cjs/index.html/index.release.html 为浏览器入口，package.json 的 scripts 暴露 build/test/release/e2e 等命令，workspaces 管理子包依赖。
