- 构建产物通过 esbuild 同时生成 ESM、IIFE 与 Node (CJS) 三种格式，并在 IIFE 模式下额外捆绑 Worker 脚本。
- 源码顶部统一注入 `Source/copyrightHeader.js` 模板中的版本号作为 banner。

- 测试数据集中在 `Specs/Data` 与 `Apps/SampleData`，被 JS Specs 与 Rust specs 共同引用以实现跨语言行为对齐。
