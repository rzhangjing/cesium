- 领域 crate 保持纯 Rust 且零框架依赖，所有数值类型使用 f64，仅在 `geometry_to_mesh`/`terrain_mesh_to_bevy` 等适配器边界处一次性转为 f32。
- 每个渲染特性以独立的 Bevy `Plugin` 形式组织在 `adapters/bevy-render/src/<feature>/mod.rs`，并通过 `add_systems(Update|Startup|PostUpdate, ...)` 注册系统。
- IO 与 GPU 交互通过 `ports/driven` 中定义的 trait（如 GpuSink、HttpFetcher）抽象，适配器实现这些 trait 而领域代码只调用 trait 方法。
- 工作区统一在顶层 `Cargo.toml` 的 `[workspace.dependencies]` 声明所有内部 crate 与外部依赖，子 crate 通过 `path = "..."` 引用，避免版本漂移。
- specs 目录下的测试文件按被测领域镜像命名（如 `camera_spec.rs`、`tileset_spec.rs`），并以 `*_spec.rs` 后缀对应原版 CesiumJS Specs 用例。
- glam 的 `fast-math` 特性被显式禁用，确保 FMA 不会引入与 CesiumJS 不同的舍入误差，所有数值断言以位级一致为目标。
