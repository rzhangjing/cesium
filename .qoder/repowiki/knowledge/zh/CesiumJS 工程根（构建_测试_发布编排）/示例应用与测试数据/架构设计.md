本模块为纯资源型叶子目录，不含可执行代码，仅由两类资产构成：
- `Apps/HelloWorld.html`：最小入口，通过 `<script src="../Build/CesiumUnminified/Cesium.js">` 引入构建产物并实例化 `Cesium.Viewer`，作为最简运行验证。
- `Apps/CesiumViewer/`：完整演示应用，`index.html` 加载本地 CSS 并通过 ES module 从 `../../Build/CesiumUnminified/index.js` 导入 Viewer、各类 DataSource（CzmlDataSource、GeoJsonDataSource、KmlDataSource、GpxDataSource）、ImageryProvider、Terrain、Inspector/DragDrop Mixin 等；`CesiumViewer.js` 解析 URL query 参数（source/sourceType/flyTo/tmsImageryUrl/lookAt/stats/inspector/debug/theme/view/saveCamera）动态装配 Viewer、地形、底图、数据源与相机视图，并将相机状态写回 URL。
- `Apps/SampleData/`：按格式分层的静态数据目录，包含 `Cesium3DTiles/`（Batched/Instanced/PointCloud/Voxel/Hierarchy/Composite/Tilesets 子集）、`models/`（glb/gltf/dae 模型）、`vector/`（V02 矢量瓦片）、`kml/`、`gpx/`、根级 `.czml/.geojson/.topojson` 等，均遵循各格式自身约定（如每个 3D Tiles 子集配套 `tileset.json`），供 Viewer 或测试直接引用。
依赖方向单向：应用 → Build 产出的 Cesium JS 库 → SampleData 中的静态资源，无反向依赖。
