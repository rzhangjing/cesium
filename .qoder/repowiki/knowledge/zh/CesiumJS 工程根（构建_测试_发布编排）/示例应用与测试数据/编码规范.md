- 示例页面统一使用标准 HTML5 模板：设置 charset、IE=edge、viewport 禁止缩放，并在 body 中预留 `#cesiumContainer` 容器。
- CesiumViewer 通过 URL query string 传递运行时配置（source、sourceType、flyTo、tmsImageryUrl、lookAt、stats、inspector、debug、theme、view、saveCamera），并以文件扩展名自动推断数据源类型。
- SampleData 中每种 3D Tiles 子集都采用「数据文件 + 同级 tileset.json」的组织方式，并按 Batched/Instanced/PointCloud/Voxel/Hierarchy/Composite/Tilesets 等特性分类存放。
- 模型与矢量数据以独立目录隔离（如 models/*/、vector/*），每个场景保持自包含，便于被 Viewer 或自动化测试按需引用。
