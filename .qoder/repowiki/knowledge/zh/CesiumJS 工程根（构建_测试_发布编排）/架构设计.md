根目录作为 monorepo 入口，以 package.json 的 workspaces 声明聚合 packages/engine、packages/widgets、packages/sandcastle 三个子包，并通过 gulpfile.js 中的 build/buildRelease/release/coverage/test 等任务串联它们的编译、类型生成、文档与打包流程；scripts/build.js 提供 buildEngine/buildWidgets/buildCesium/bundleWorkers/glslToJavaScript/createCombinedSpecList 等共享构建原语，被根 Gulp 与各子包复用。测试层由 Specs/* 下的 Jasmine/Karma 用例与 Specs/e2e 下的 Playwright E2E 组成，test 任务根据 --workspace/--include/--exclude/--webglStub 等参数动态组装文件列表与代理，使 engine/widgets/CesiumJS 三层共用同一套运行环境。发布流水线通过 .github/workflows、.husky/pre-commit、launches/*.launch 以及 make-zip/release/website-release 任务协同完成版本注入、zip/tgz 产物与 GitHub Status 上报。Rust 重构期间，根级测试套件（12,823 个 Specs）作为唯一验收基准，所有移植失败默认视为 Rust 实现缺陷并修复。
