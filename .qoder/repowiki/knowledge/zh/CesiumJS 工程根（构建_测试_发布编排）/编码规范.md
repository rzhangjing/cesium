- 所有跨子包的构建与测试入口统一通过 npm scripts 调用 gulp 任务，而非直接执行 node 脚本。
- 子包 Source/ 与 Specs/ 采用镜像目录结构，Spec 文件名以 *Spec.js 结尾并由 createCombinedSpecList 自动发现注册。
- 构建产物统一输出到 Build/ 或各 packages/*/Build/ 目录，Source 中仅保留原始 JS/GLSL，不提交生成代码。
- 测试通过 Karma client args 传递 include/exclude/webglValidation/webglStub/release/grep 等运行时开关，按类别筛选用例。
- 发布流程使用 postversion 钩子扫描所有 package.json 并同步更新对已升级 workspace 的版本依赖。
