该模块为纯文档目录，按主题划分子目录：`Contributors/` 下以独立子目录组织各类贡献指南（BuildGuide、CodingGuide、TestingGuide、ReleaseGuide 等），每个指南以 `README.md` 为主入口并附带截图或 PDF；`CustomShaderGuide/` 提供 CustomShader 类的使用说明；`FabricGuide/` 存放 Fabric 材质系统的示例图片（AlphaMap、DiffuseMap、SpecularMap 等）；`Schemas/Fabric/` 包含 Fabric 材质的 JSON Schema 定义与示例；`Images/` 集中存放 API 参考文档所需的截图。根级 `README.md` 作为导航索引，将各子指南链接起来，整体无代码逻辑，仅作为仓库的静态知识资产。
