本模块按职责拆分为三个相互独立的子目录：
- ast-grep/：基于 ast-grep 的 JavaScript 代码风格与语义规则集合，每个规则以 YAML 文件（rules/*.yml）声明匹配模式、严重级别与适用路径，并通过同名的 tests/*.test.yml 加 __snapshots__/* 快照进行断言验证，形成规则即测试的结构。
- jsdoc/：JSDoc 与 tsd-jsdoc 的配置与自定义扩展，conf.json 指定扫描 packages/engine/Source 与 packages/widgets/Source 并排除 ThirdParty/Workers；ts-conf.json 复用相同源配置但切换模板与输出目标以生成 Cesium.d.ts；cesiumTags.js 通过 defineTag 注册 internalConstructor、glsl*、performance、demo、experimental、privateParam、import 等 JSDoc 标签，cesium_template/ 下存放定制 HTML 模板与静态资源。
- rollup-plugin-strip-pragma/：自研 Rollup 插件，使用 magic-string 在 transform 阶段匹配 //>>includeStart(...)/...//>>includeEnd(...) 形式的条件编译块并按 pragmas.* 开关剔除，配合 rollup-pluginutils.createFilter 实现 include/exclude 过滤。
各子目录均为独立 npm CommonJS 包，由上层构建脚本按需调用。
