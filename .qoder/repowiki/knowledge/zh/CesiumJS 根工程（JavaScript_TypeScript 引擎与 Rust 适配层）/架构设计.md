根目录作为多语言工程的编排中心：
- JavaScript/TypeScript 侧：`packages/engine`、`packages/widgets`、`packages/sandcastle` 三个 npm workspace 由 `gulpfile.js` 统一调用 `scripts/build.js` 中的 `buildEngine`/`buildWidgets`/`buildCesium` 流水线构建，产物输出到 `Build/`；源码位于 `Source/`，测试在 `Specs/` 使用 Jasmine+Karma，端到端测试用 Playwright。
- Rust 侧：`cesiumrust/` 是独立的 Cargo workspace，包含 domain/crates/adapters/application/specs 等子包，通过 Bevy 渲染适配器与 JS 引擎解耦。
- 顶层 `package.json` 声明依赖 `@cesium/engine`、`@cesium/widgets`，并通过 `workspaces` 字段把三个子包纳入同一构建管线；`server.js` 提供本地开发服务器，`launches/*.launch` 和 `.github/workflows` 提供 IDE/CI 入口。
- 两个语言栈之间没有运行时耦合，Rust 引擎通过独立 Cargo workspace 编译，JS 引擎通过 npm 发布，二者共享 Cesium 数据格式（glTF、3DTiles、CZML 等）作为契约。
