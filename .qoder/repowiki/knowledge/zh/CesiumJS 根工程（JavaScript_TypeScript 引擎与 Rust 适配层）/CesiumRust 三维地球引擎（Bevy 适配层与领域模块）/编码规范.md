- 每个领域功能拆分为独立 crate（如 cesium-geospatial、cesium-scene 等），在 workspace Cargo.toml 中集中声明路径依赖，避免重复版本管理。
- 端口通过 `Send + Sync` trait 抽象外部依赖，统一使用 `PortResult<T>` 和 `PortError` 枚举封装错误类型。
- domain 层坚持 f64 精度与零框架依赖，adapter 层负责在 f64→f32 边界进行显式转换（如 `geometry_to_mesh`、`terrain_mesh_to_bevy`）。
- Bevy adapter 通过 `Plugin` trait 注册系统，使用 `#[derive(Component)]` / `#[derive(Resource)]` 标记组件与资源。
- 测试文件命名遵循 `<feature>_spec.rs` 约定，按 core/datasources/renderer/scene/widgets 分类组织，与 CesiumJS Specs 一一对应。
