项目为 Cargo workspace，按六边形架构分三层：
- `domain/`：纯 Rust 领域模块（geospatial、time、camera、datasource、scene、material、globe、terrain、tileset、imagery、effects、shadow、crs、kml、gpx、provider、styling、quadtree、primitives、animation、implicit-tiling、vector、scene-mode、performance、voxel、widgets），不依赖任何框架，仅通过 glam 做 f64 数学计算。
- `ports/`：定义双向 trait 契约——`driven/src/lib.rs` 声明被外部系统依赖的接口（TileFetcher、ImageryProvider、TerrainProvider、GpuSink、Decoder、Cache、SystemClock、RenderContext），`driving/src/lib.rs` 声明对外暴露的 API（ViewerApi、CameraControl、DataSourceManager、ImageryLayerManager、TerrainManager、EntityManager、Picking）。
- `adapters/`：实现 ports 的具体适配器——`bevy-render` 实现 GpuSink 并将 domain 的 f64 GeometryData 转为 Bevy Mesh（f32），`decoders` 实现 Decoder，`network` 实现 TileFetcher。
- `application/cesium-app`：组合所有 crate 的 Bevy App 入口，装配插件并启动渲染循环。
- `specs/`：对应 CesiumJS Specs 的集成测试套件，覆盖 core/datasources/renderer/scene/widgets 各子域。
依赖方向严格单向：adapters → ports → domain，application 聚合 adapters + ports；domain 之间无循环依赖。
