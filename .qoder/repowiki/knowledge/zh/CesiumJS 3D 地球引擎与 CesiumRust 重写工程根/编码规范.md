- Rust domain crate 之间通过 workspace dependency 声明相互引用，并在 `Cargo.toml` 的 `[workspace.dependencies]` 中集中管理版本，避免重复声明。
- Rust 代码严格使用 f64 进行领域计算，仅在 GPU 边界转换为 f32，且显式禁用 glam 的 fast-math 特性以保持与 CesiumJS 的位级一致。
- CesiumRust 通过 ports/driven 与 ports/driving trait 将领域逻辑与 Bevy/IO 解耦，adapters 层实现具体后端，使 domain 可独立测试。
- JS 构建管线统一通过 Gulp 任务编排，源文件扫描排除 Shaders、ThirdParty/Workers 等目录，并由 `scripts/build.js` 中的 buildEngine/buildWidgets/buildCesium 函数复用。
- Specs 与示例数据分别集中在 `Specs/Data` 与 `Apps/SampleData`，按格式（CZML、KML、glTF、3D Tiles 等）分目录组织，供 JS 与 Rust 两侧共享或对照。
- 代码质量通过 ESLint、Prettier、markdownlint、ast-grep（sg scan）与 Husky pre-commit 钩子在提交前统一校验。
