仓库采用双语言多包结构：
- JavaScript/TypeScript 侧（根目录）：通过 npm workspaces 管理 `packages/engine`、`packages/widgets`、`packages/sandcastle` 三个子包，由 `gulpfile.js` + `scripts/build.js` 驱动 esbuild 构建 IIFE/ESM/CJS 产物，Karma+Jasmine 运行 Specs，Playwright 运行 e2e；`Source/` 仅保留版权头，实际源码位于 packages 下。
- Rust 侧（`cesiumrust/`）：按六边形架构组织，`domain/` 下 31 个纯 Rust crate（geospatial、terrain、tileset、scene、material 等）无框架依赖；`ports/driven` 与 `ports/driving` 定义 IO 与应用 API 契约；`adapters/` 提供 bevy-render、network、decoders 实现；`application/cesium-app` 组装 Bevy App 并注册 13 个渲染插件；`specs/` 从 CesiumJS Specs 移植集成测试以验证 bit-exact 数值一致性。
- 顶层还包含示例应用（`Apps/`）、文档（`Documentation/`）、工具链（`Tools/jsdoc`、`Tools/ast-grep`、`Tools/rollup-plugin-strip-pragma`）及 VS Code/GitHub Actions 工作流配置。
