JS 侧：`npm run build` 调用 gulp 构建 engine/widgets/cesium；`npm run test` / `--all` / `--webglValidation` / `--release` 控制 Karma 测试集；`npm run test-e2e` 运行 Playwright e2e。Rust 侧：需安装系统依赖 `libudev-dev libasound2-dev libxkbcommon-dev vulkan-validationlayers`，通过 `cargo run` 启动交互式地球查看器，`cargo test --workspace` 运行全部 specs。
